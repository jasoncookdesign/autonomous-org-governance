# Knowledge Base

The sandbox knowledge base. Managed by the Knowledge Director under `capabilities/knowledge-management.md`. CEO read access via Google Drive mirror.

All content in this folder is derived from airlock-cleared artifacts. No raw source data is stored here. See `index.md` for the master index of all KB articles.

## Structure

| Folder / File | Contents |
| --- | --- |
| `index.md` | Master index -- maintained by the Knowledge Director |
| `projects/` | Active and archived project context |
| `research/` | Synthesis documents, competitive analysis, reference material |
| `operations/` | Runbooks, checklists, workflow notes |
| `technology/` | Stack decisions, tool evaluations, architecture notes |
| `creative/` | Content, brand, and creative production context |
| `people/` | Sanitized contact and collaborator context (no restricted PII) |
| `finance/` | Sanitized financial analysis and budget model artifacts |
| `inbox/` | Staging area for newly ingested artifacts pending classification (48-hour classification window) |
| `archive/` | Aged Class C content moved here per the 180-day retention schedule |

## Classification and Retention

| Class | Retention |
| --- | --- |
| A -- Public | No limit |
| B -- Internal | No limit |
| C -- Sensitive | 180 days from ingestion; archive after; deletion requires CEO approval |
| D -- Restricted | Not permitted; escalate immediately |
