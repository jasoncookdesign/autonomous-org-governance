# Workloads

Workload definitions in all lifecycle states. A workload is a defined body of recurring or project-scoped work assigned to one or more directors. Workloads are governed by the capability policies of the assigned director(s).

## Contents

| Folder | Description |
| --- | --- |
| `proposed/` | Workload definitions drafted and awaiting CEO approval |
| `active/` | CEO-approved workloads currently in execution |
| `completed/` | Workloads that have reached their defined end state |
| `archived/` | Retired or superseded workloads retained for audit continuity |

## Filing Convention

Use `templates/workload-template.md` for all workload definitions. File as: `[workload-slug].md` within the appropriate lifecycle folder.
